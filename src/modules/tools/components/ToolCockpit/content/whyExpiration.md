## Why Do Tools Expire?

All of the tools on HabiTools have an expiration timer. When the timer runs out, it will deactivate the tool and remove it's related data. This is important for long-term support and use of the Habitica API.

So why do tools expire?

### 1: Habitica API Requirement
The biggest reason tools expire is compliance with the Habitica API rules. Automations are expected to stop eventually unless a user is actively using them. An expiration helps ensure every tool stays tied to real user activity.

### 2: Protecting Habitica and Its Users
This is one way we support thoughtful, responsible use of the Habitica API. We do not want inactive accounts leaving behind ghost scripts that run forever. Those unnecessary calls can add avoidable load and contribute to downtime risk for everyone.

### 3: You Can Refresh Forever
If you are using a tool, a quick refresh every once in a while is all you need! As long as you're still active and can click ` Refresh Expiration ` on each of the tools and automations you're using before they expire, then they won't ever deactivate!
