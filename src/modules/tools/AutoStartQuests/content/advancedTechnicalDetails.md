This tool works by adding a webhook to your Habitica account that tells Habitica to send a message to HabiTools whenever a quest opens. HabiTools uses this as the signal to start the timer. Technically the timer actually uses a scheduled routine (cron task) to start the quest instead of a classic in-memory wait.

This tool also validates several factors when the quest opens before starting the timer. For example, it makes sure that you're either the quest leader or party leader. If you aren't, then there's no use in starting the timer because you can't start the quest. Lastly, if a quest gets started early or canceled, the cron task will catch this and will not try to start a quest.

Regarding the 3 hour option, this exists because very rarely the Habitica API will fail to send a webhook to it's destination, which we use for the auto-accept tool to signal that a quest is available to join. For this scenario, a fallback routine schedule runs every 3 hours to do the same check for a quest. The 3 hour option gives time for all of these routines to play-out and finalize to get everyone into the quest before starting it.
